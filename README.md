# GOAL Learning Journey

This repository is a single long-term learning path for becoming a strong software engineer and then advancing into AI engineering, agentic AI, AI systems, and AI architecture.

## Learning progression

Developer
→ Senior Engineer
→ AI Engineer
→ Agentic AI Engineer
→ AI Systems Engineer
→ AI Software Architect

## Core principle

This is one evolving repository, not a collection of disconnected projects. Every topic is connected to the same master application: an AI-powered CRM / project management platform.

## Repository structure

The repository is organized by curriculum stage and by the master project. Each section contains notes, implementations, debugging logs, diagrams, assessments, and architecture decisions.

## Important rules

- Do not create unrelated projects.
- Do not fill the repo with copied tutorial content.
- Keep reflections, mistakes, and debugging notes personal and honest.
- A concept is complete only after theory, implementation, practice, project application, testing, explanation, and assessment are complete.
- Never advance automatically.

## Master project

The master project evolves gradually:

- Stage 1: React + TypeScript → Spring Boot → PostgreSQL
- Stage 2: Redis
- Stage 3: Kafka / workers
- Stage 4: Python AI service + LLM
- Stage 5: RAG + CRM AI assistant
- Stage 6: Agentic AI + tools + CRM / DB / notifications
- Stage 7: MCP + enterprise tools

This repository currently contains the structure and placeholders needed for the journey.
